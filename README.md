# 多动画时间线引擎

零构建依赖的浏览器动画示例，组合使用 Web Animations API、Canvas 2D 和 Web Worker，支持复杂编排、并发剪辑、关键帧插值、暂停恢复、循环和运行时降级。

## 运行

```bash
npm start
```

然后打开 `http://localhost:5173`。模块 Worker 需要通过 HTTP 服务访问，不要直接双击 `index.html`。

## 验证

```bash
npm test
npm run benchmark
```

- `npm test`：校验插值、冲突检测、填充优先级、循环、暂停恢复。
- `npm run benchmark`：模拟 240 条剪辑、5400 帧采样；当前平均采样耗时约 0.1ms，为渲染保留绝大多数 16.7ms 帧预算。

## 架构

- `src/timeline.js`：纯函数时间线编译器和采样器，检测同目标同属性并发冲突，支持线性/贝塞尔缓动、数字、数组、对象、颜色和 CSS 变换插值。
- `src/playback-engine.js`：虚拟时间时钟。播放时只记录 `virtualTime + anchorTime`，暂停冻结虚拟时间，恢复后继续，不依赖逐帧误差累加。
- `src/scheduler-worker.js`：Worker 内复核时间线、跟踪剪辑开始/结束边界、汇总平均帧间隔与丢帧。
- `src/scheduler-fallback.js`：Worker 不可用、加载超时或通信失败时的主线程边界调度器。
- `src/waapi-layer.js`：DOM 元素使用 WAAPI 绝对时间关键帧，与 Canvas 共用同一时间原点；WAAPI 不可用时由 rAF 采样结果写样式。
- `src/canvas-renderer.js`：Canvas 2D 渲染，复用状态对象，按高/中/低质量动态调整 DPR、粒子数和阴影。
- `src/main.js`：组合播放、渲染、调度、UI、遥测和异常处理。

## 并发规则

- 不同目标可完全并发。
- 同一目标的不同属性可拆成多个剪辑并发，例如旋转和透明度。
- 同一目标同一属性只允许在剪辑端点衔接，不允许实际播放区间重叠。
- 已开始的剪辑优先于未来剪辑的 `backwards` 预填充；活动剪辑优先于旧剪辑的 `forwards` 保持值。

## 暂停恢复与循环

- 暂停立即把当前真实时间折算成虚拟时间并冻结。
- 恢复只重设真实时间锚点，Canvas 与 WAAPI 从同一个虚拟时间继续。
- 循环时播放时钟和 WAAPI 时间轴同步回绕，Worker 补发跨周边界事件。

## 异常降级

- 时间线编译错误：显示致命错误面板，阻止进入错误状态。
- Worker 不可用、超时、加载失败或通信失败：自动切换主线程调度。
- WAAPI 不可用或单个动画初始化失败：自动切换 Canvas 同帧驱动的样式回退。
- Canvas 上下文丢失：暂停绘制并提示，上下文恢复后继续。
- 持续渲染异常：停止 Canvas 绘制，保留播放控制和状态展示，避免异常风暴。
- 连续高帧耗时：自动降低 DPR、粒子数和阴影，稳定后再逐步恢复。

## 操作

- 点击“播放”或按空格播放/暂停。
- 拖动时间轴可在运行或暂停状态下跳转。
- 右侧面板显示当前时间、FPS、丢帧、渲染质量、Worker 状态和最近剪辑边界。
